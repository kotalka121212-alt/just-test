### 📑 ТЕКУЩЕЕ СОСТОЯНИЕ ПРОЕКТА: JUST-TEST (NEXUS)

#### 1. Основной стек (Технологии)

* **Язык:** C++ (99.9%)
* **Система сборки:** CMake
* **Компилятор:** MinGW (UCRT64)
* **Целевые платформы:** Windows (сейчас), Android (в планах для `mobile.exe`)

#### 2. Список подключенных библиотек (Libraries)

* **Qt6 (Core, Gui, Widgets):** Основной каркас для будущей графики.
* **ImGui:** Интерфейс для инструментов и дебага (уже в сборке).
* **ZeroMQ (libzmq):** Сетевой движок для обмена данными.
* **GLAD / OpenGL:** Низкоуровневая графика (был "оранжевый куб").
* **libusb:** Библиотека для прямой работы с USB-железом (требует фикса путей).
* **NFC:** Модуль для чтения/хака карт доступа.
* **SFML:** В планах для командного окна.

#### 3. Архитектура и модули

* **Nexus Engine:** Твой основной движок (папка `engine`).
* **kt_studio (v1.0.1.0):** Математика, факториалы и кастомный линкер.
* **test_client / server:** Зачатки клиент-серверной системы.
* **mobile.exe:** Будущая хакерская утилита для Android (Root, NFC, USB).

#### 4. Текущие задачи и баги

* **Критическая ошибка:** Ошибка линковки `libusb-1.0.dll.a` в `mobile.exe` (путь `G:/progects_c++/mingw/ucrt64/lib/` пуст или не содержит либу).
* **Ближайший план:** Настройка Android NDK, установка ADB и первый запуск ImGui на смартфоне.
